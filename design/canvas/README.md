# Design canvas source

The approved screens, as published to the Cali Care design canvas
(https://claude.ai/artifact/DgxTwrnEfu9GHkfp44HwD6). Kept here so the
SwiftUI build can match them exactly. `tokens.css` is the source for the
values in `Core/DesignSystem/DesignSystem.swift`.

These files render only inside the canvas (they use its runtime). Edit
the canvas, then copy the files back here.
