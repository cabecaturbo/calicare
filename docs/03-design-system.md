# Design System and Voice

## Feel
Calm, warm, and well made, like a linen notebook. Not clinical blue, not pastel baby app.

## Colors
| Token | Hex | Use |
|---|---|---|
| background | #F8F3EA | App and card backgrounds |
| card | #FFFFFF | Stat and content cards |
| ink | #2B2622 | Main text |
| muted | #6B6259 | Labels, captions |
| accent (sage) | #4F6F57 | Buttons, positive trends |
| sage dark | #3F5E47 | Text on light sage |
| clay | #8A5A3C | "Avoid" and "worth watching" labels |
| sand | #F0E6D6 | Callout boxes |
| severity low | #C9D6C9 | Calm skin days |
| severity medium | #8FA995 | Medium days |
| severity high | #3F5E47 | Itchy days |
| night background | #1E1B18 | 8 PM – 7 AM palette |

Rules:
- Never red for "bad." Severity uses darker sage, measured by symptoms (itch, sleep, spread), not skin color. Eczema looks purple, gray, or brown on darker skin.
- Body map illustrations offer a range of skin tones.
- Text contrast at least 4.5:1.

## Type
- Headings: Fraunces (serif), weight 500–600.
- Body: DM Sans, weight 400–600.
- Both open-license; bundled in the app.
- Supports Dynamic Type.

## Shape and spacing
- Cards: 18px corner radius, generous padding (18–20px).
- Pills: fully rounded.
- Touch targets at least 44pt. Night buttons larger.

## Voice
- Plain, warm, short. Like a kind friend who's been there.
- Honest about uncertainty: "worth watching," "not enough data yet." Never "cause."
- Never shame: no streaks, no "you missed," no failure states. Missing days means nothing; welcome parents back.
- Occasional acknowledgment after hard stretches, sincere and rare.
- Never medical advice. Footer on shared reports: "Not medical advice."

## Night mode
- Automatic 8 PM – 7 AM.
- Dim warm background, no bright whites, big one-hand buttons.

## Report cards (designed on canvas)
- Weekly card (600×750): headline sentence ("A calmer week"), trend pill, good nights as 7 dots, itchy wake-ups vs last week, routine completion, new safe foods, skin-by-day bars, one "worth watching" callout, footer.
- Messages bubble: compact version with 3 stats and "Tap to see full week."
- Caregiver card: bedtime routine steps, safe snacks, please avoid, "if she's scratching," contact.
- Other versions planned: partner (daily), daycare, doctor (PDF), insurance (treatment history PDF).
